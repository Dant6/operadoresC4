# Capacitación Psicosocial C4 – Línea 123

Sitio web estático con los contenidos del documento Word **Capacitacion Psicosocial Personal Nuevo** incorporados en su totalidad (192 párrafos no vacíos), respetando el orden original de los módulos.

## Archivos
- `index.html`: contenido y estructura de la capacitación.
- `css/styles.css`: estilos responsivos.
- `js/app.js`: navegación móvil y resaltado de sección.

## Publicar en GitHub Pages
1. Descomprime el ZIP.
2. Sube `index.html`, `css/` y `js/` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio.

El video solicitado se encuentra al inicio del módulo de habilidades emocionales y se carga desde YouTube.
